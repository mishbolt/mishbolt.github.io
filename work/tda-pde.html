Master’s thesis · 2023

Topological data analysis for PDE parameter estimation

Northern Arizona University

I investigated the use of persistent homology and machine learning to infer parameters from spatial patterns generated by a nonlinear partial differential equation.

Problem

The thesis considers numerically generated surfaces from an anisotropic Kuramoto–Sivashinsky-type PDE. The aim was to distinguish the parameter values used to generate them by extracting features from the resulting patterns.

Methods

The dataset contained 850 surfaces of size 200 × 200 spanning 17 parameter classes, with 50 initial conditions per class. I computed cubical persistent homology, constructed representations including persistence images, and compared classification methods.

Model evaluation included five-fold cross-validation, hyperparameter searches, and comparisons with models trained directly on the original surfaces. Experiments used Python and computing resources at Northern Arizona University.

Results

In the thesis experiments, a random-forest classifier using persistence images achieved 79.96% mean five-fold cross-validation accuracy. Results varied by classifier and feature representation; these figures describe this specific simulated dataset.
