Topological data analysis for PDE parameter estimation

Master’s thesis · Northern Arizona University · 2023

Problem

My master's thesis examined parameter estimation from numerically generated surface patterns for an anisotropic Kuramoto–Sivashinsky-type partial differential equation. The goal was to test whether topological descriptors provide useful information for identifying the parameters used in the simulations.

Methods

The dataset contained 850 simulated surfaces of size 200 × 200, representing 17 parameter classes and 50 initial conditions per class. I computed cubical persistent homology and evaluated representations including persistence images. Classification experiments compared random forests, support vector machines, k-nearest neighbors, and neural networks.

I used cross-validation and hyperparameter searches to compare topological representations with models using the original surface data.

Results

In these experiments, a random forest trained on persistence-image features reached 79.96% mean accuracy under five-fold cross-validation. The comparison was specific to the simulated dataset and classification setup used in the thesis.
