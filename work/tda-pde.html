Case study / scientific machine learning

Can topology reveal hidden parameters?

Master’s thesis · Northern Arizona University · 2023

This project investigated whether topological features of simulated spatial patterns could help infer the parameter values that generated them.

The problem

Numerical solutions of a nonlinear partial differential equation can produce complex surfaces. Recovering model parameters from those snapshots is an inverse problem: observed patterns may be similar even when their underlying parameters differ.

I studied surfaces generated by an anisotropic Kuramoto–Sivashinsky-type PDE and investigated whether persistent homology could summarize their geometry in a form useful to machine-learning models.

The computational workflow

The study used 850 surfaces of size 200 × 200 across 17 parameter classes, with 50 randomized initial conditions per class. I computed cubical persistent homology, transformed persistence information into engineered representations such as persistence images, and compared multiple classifiers.

The pipeline included cross-validation, hyperparameter searches, and comparisons between raw surfaces and topological features. Experiments used Python libraries and NAU's Monsoon computing resources.

Selected results

79.96%mean five-fold CV accuracy, RF + persistence images
77.76%best reported kNN with topological features
10.71%kNN using raw surfaces, comparison

These results are specific to the thesis dataset and its evaluation setup; they are not claims of performance on unseen physical systems.

What I took away

Representations matter. In this setting, persistent homology captured information that made classification substantially more effective for some models. The work brought together numerical PDE data, computational topology, and careful empirical evaluation.
